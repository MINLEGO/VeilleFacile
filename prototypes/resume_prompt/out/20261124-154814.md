## De quoi ça parle
fast-anything is a tool that profiles slow Python, Node, Ruby, or other language applications, identifies the few functions consuming the most runtime, and uses a coding agent to port only those hot functions to Rust. It records real inputs, verifies behavioral equivalence on every call plus edge cases, and swaps the Rust code in transparently—fully reversible with a single command.

## Pourquoi c'est intéressant
Instead of rewriting entire apps—a months-long compile and risk grind—fast-anything targets just the 5% of code that matters, proving correctness before swapping it in for low-risk, reversible optimization.

## Points clés
- Profiles apps and ranks hot functions by runtime impact and portability to Rust
- Records real inputs and verifies output equivalence (1e-9 float tolerance, error matching, edge cases like NaN, empty inputs)
- Fully reversible: enable/disable swaps Rust in/out byte-for-byte without changing original code
- Ports only the outermost loop, not inner functions called millions of times, achieving speedups up to 116x
- Compiles one-function Rust crates in seconds; all ports share a single `.fast/target` cache
- Supports 9+ languages (Python, Node/TS, Ruby, Java, Go, PHP, C, C++, C#, R) via C/JSON bridges or native runtimes

## Pour qui
Developers maintaining slow Python, Node, Ruby, or other language apps who want targeted Rust-speed boosts without rewriting the whole codebase or risking behavioral drift.
