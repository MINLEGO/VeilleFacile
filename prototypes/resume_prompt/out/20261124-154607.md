## De quoi ça parle
Inkling 2 Mini is a 26.4-billion-parameter looped Mixture-of-Experts model from Thinking Machines Lab that can run offline on a laptop. Its "looping" architecture processes the middle layers of the model three times per token, improving reasoning quality for agentic coding and tool-use tasks without increasing parameter count.

## Pourquoi c'est intéressant
It achieves top scores among open-weights models under 100B parameters on benchmarks like DeepSWE v1.1 (48.2%) and Vals Index v2.2 (46.5%) while remaining compact enough (~20GB) for local deployment on consumer hardware.

## Points clés
- 26.4B total parameters, 3.4B active, 5.4B weight activations per token via looping
- Middle 12 of 24 layers run three times per token to boost serial reasoning depth
- Leads open-weights models <100B on DeepSWE v1.1 (48.2%) and Vals Index v2.2 (46.5%)
- ~20GB memory footprint; runs offline on MacBook Pro M5 Pro 48GB, built a flight simulator in minutes
- Trained with NVFP4 precision (20 layers) and MXFP8 (last 4 layers); quantized GGUF versions available
- Limited multi-turn chat: 50.0% on MultiChallenge, 33.4% on ComplexConstraints v1.1; trails larger models on some reasoning benchmarks

Researchers and engineers wanting to experiment with efficient, locally runnable models for agentic coding, tool use, or looped transformer interpretability should reopen this when seeking a compact model that balances reasoning depth with laptop-scale deployment.
